# 3.引入知识库，降低大模型决策失误概率

### 建立目标机器人或相似机器人能力知识库：
管理者可以更新机器人的能力库，使用者可以自主挖掘在特定场景下的机器人能力，通过上报更新能力请求，在管理者测试之后由管理者将该使用者的能力完成场景添加进能力知识库

# 5.模型轻量化与边缘部署

如果动作是抓取，那么对于模型所识别的图像，可以将清晰详细的图片内容进行蒸馏，例如抓取香蕉：可以将香蕉的边缘图像进行清除保留标记，将其它物体以三维空间红色马赛克表示隔离，加快响应速度。
